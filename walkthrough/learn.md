# Learn Mimic

The tutorial opens beside your code, from `mimic man`, so it always matches
the Mimic you have. Every example in it is a complete program:
**Mimic: Run an Example from the Manual…** runs one, and the REPL
(*Mimic: Open REPL*) is there to try a line.

The whole manual: **Mimic: Open the Manual…**; a word in your code: F1 on it,
or `Cmd/Ctrl+Alt+M`.
