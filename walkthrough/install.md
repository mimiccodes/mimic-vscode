# Install Mimic

**Mimic: Install or Update Mimic** downloads the release for your machine from
[GitHub](https://github.com/mimiccodes/mimic/releases), checks it against the
release's `SHA256SUMS`, and runs its installer: `mimic` goes into
`~/.mimic/bin` (on Windows `%USERPROFILE%\.mimic\bin`) and onto your PATH.

To install by hand, unpack the release and run `install.sh` (or
`install.cmd` on Windows).

The status bar shows the Mimic in use and what it can do; click it to
update Mimic, choose another `mimic`, or see the log.
